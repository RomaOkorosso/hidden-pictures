# Задание для автономного Codex

Распакуй архив в рабочую папку Codex. Если исходники игры уже есть, открой именно их проект и передай ему эту папку как handoff.

Вставь запрос из `PROMPT_TO_PASTE.txt`. Исходные 100 карточек приложены внутри `assets/picture_cards_100.zip`; отдельно скачивать их не нужно.

Это пакет задания и графики, а не уже написанная игра. Codex должен самостоятельно написать, проверить и опубликовать рабочую версию.

Развёртывание: GitHub Actions → GitHub Pages; аккаунты и комнаты → Firebase. Actions не служит постоянно работающим сервером. Бесплатные тарифы и возможность публикации агент проверяет до настройки. Доступность браузера зависит от среды запуска Codex; без браузерного инструмента агент даст ссылки для входа, но не сможет сам открыть вкладки.

Владельцу остаются вход, 2FA/CAPTCHA и выбор аккаунта при неоднозначности. Платные сервисы не разрешены. Существующие чужие репозитории и настройки нельзя изменять.
